# Web Services

Piksel geospatial data can be accessed and used directly from GIS software, web mapping applications, and other systems. Web Services let users display maps as layers, serve maps as tiles, or retrieve raster data for analysis, without first copying or downloading the data manually.

Piksel provides Web Map Service (WMS), Web Map Tile Service (WMTS), and Web Coverage Service (WCS) for different needs. WMS renders maps on request, WMTS serves maps as tiles, and WCS provides raster data for further processing.

Further explanation of the differences and their use is available on the [Web Service Types](./service-types) page.

Each service is available at the following addresses:

```text
https://ows.staging.piksel.big.go.id/wms
https://ows.staging.piksel.big.go.id/wmts
https://ows.staging.piksel.big.go.id/wcs
```

These addresses work with any application that supports WMS, WMTS, or WCS. Setup steps for QGIS and ArcGIS Pro are available on the [Use in GIS Software](./gis-software) page.
