# Training Programme

Geospatial data and satellite imagery do not always provide the information needed straight away. They must be selected, processed, and analysed using methods suited to the question being investigated. Training helps participants build these skills.

The Piksel team supports training by providing materials or expert speakers on using geospatial data, satellite imagery, and analysis technologies built on Open Data Cube. This support is available to government agencies, universities, organisations, and communities.

## Training Scope

Training needs vary. Some participants are new to geospatial data and the Piksel platform, while others need more in-depth technical training in data processing and analysis. The programme can be tailored to the group's aims and experience.

Training may cover:

- Finding satellite imagery for a given area and time period through online catalogues, then loading analysis-ready data directly into Piksel without downloading large datasets. Open Data Cube makes it possible to work with imagery from different periods as a time series.
- Processing and analysing data with Python directly in Piksel's cloud environment, which can be accessed from any device with an internet connection. The process is script-based, with each step recorded so the analysis can be reproduced.
- Automating geospatial data production on a national scale with Argo Workflows. The target area is divided into thousands of grid cells for parallel processing, instead of running the same workflow one grid at a time.
- Developing GeoAI models using machine learning and geospatial data in Piksel's cloud environment.

Some technical material is easier to follow with a basic familiarity with geospatial concepts, remote sensing, or Python. The length and depth of the training can be tailored to the group's needs and experience.

## Training Request Process

1. Training requests are submitted to Piksel by email at piksel@big.go.id.
2. The Piksel team receives the request.
3. BIG's Pusat Pengembangan Kompetensi Informasi Geospasial helps deliver the training.
4. The Piksel team coordinates the training needs and scope with the requesting party.
5. The schedule, content, and delivery arrangements are agreed together.
6. The training is delivered according to the agreed schedule.
