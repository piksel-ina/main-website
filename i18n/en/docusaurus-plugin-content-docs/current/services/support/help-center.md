# Help Centre

The documentation explains common tasks. Use the Help Centre for questions that are not covered there, problems with the platform, or requests related to account or data access.

Email the Piksel team at:

**piksel@big.go.id**

## What We Can Help With

The Piksel team can help with access to services and data, platform issues, questions the documentation does not answer, and suggestions for improving Piksel.
