# Piksel Explorer

How can we know exactly **where** and **when** data is available? Before starting any analysis, we can answer this question by inspecting the data at [Piksel Metadata Explorer][exp_lnk].

:::info Start exploring
Open the [Metadata Explorer][exp_lnk]
:::

## Map or Explorer {#map-or-explorer}
[Piksel Metadata Explorer][exp_lnk] and [Piksel Maps][map_lnk] look similar, but they are designed for different purposes.

Use [Piksel Maps][map_lnk] if:

- You want to view and interact with a product or dataset in a map viewer.

Use [Piksel Metadata Explorer][exp_lnk] if:

- You want to know exactly where and when you can find the data.

## Open Piksel Explorer {#open-piksel-explorer}
Go to https://explorer.staging.piksel.big.go.id/products. This will display the Metadata Explorer user interface.

![explorer-homepage](/img/explorer/explorer-home1.webp)

Piksel Explorer has four main sections:

1. **Product selection**: This section shows the currently selected product. Click the selected product name to open the product menu.

2. **Time period**: This section shows the time period used to display the selected product. Click the selected time period on the grey menu bar to open the time selection menu. The blue bar chart shows data availability over time for your selected product.

3. **Map view**: This displays the location of data availability for the selected time period and product. Blue-coloured tiles indicate the presence of data.

4. **Product information**: The sidebar displays further information about the data for the selected time period and product — including the number of selected datasets, total area, and coordinate reference system.

## Select Landsat 9 Product {#select-l9-product}
1. Click the **product selection** bar to open the menu. Select **ls9_c2l2_sr**. This will select the Landsat 9 product.

![explorer-l9](/img/explorer/explorer-home2.webp)

2. Click the **time** bar to open the menu. Select **2022**. This will display all Landsat 9 datasets for the year 2022.

![explorer-2022](/img/explorer/explorer-home3.webp)

3. Click the **all months** bar to open the menu. Select **August**. This will display all Landsat 9 datasets for August 2022.

![explorer-aug](/img/explorer/explorer-home4.webp)

4. Click the **all days** bar to open the menu. Select **11**. This will display all Landsat 9 datasets for 11 August 2022.

![explorer-11th](/img/explorer/explorer-home5.webp)

5. The **map view** will now show all Landsat 9 datasets for 11 August 2022 as blue boxes. Use the **+** button on the map to zoom in, then click and drag to pan.

![explorer-zoom](/img/explorer/explorer-home6.webp)

## Zoom in on East Nusa Tenggara {#zoom-ntt}

Use the **+** button on the map to zoom into the East Nusa Tenggara region.

![explorer-ntt](/img/explorer/explorer-home7.webp)

When we hover over East Nusa Tenggara, we can see there is one dataset for that area on 11 August 2022. Click the dataset on the map. You can now see a preview of the data for that tile, along with all the associated metadata below the map view.

![explorer-ntt2](/img/explorer/explorer-home8.webp)
