# Data Explorer

Data Explorer is Piksel's metadata catalogue for finding available satellite data. It shows the product, spatial and temporal coverage, and metadata for each dataset. Product documentation is available under [Data Products](../../category/data-products/).

:::info Start exploring
Open [Data Explorer][exp_lnk]
:::

## Maps or Explorer {#map-or-explorer}

[Data Explorer][exp_lnk] and [Piksel Maps][map_lnk] serve different purposes.

[Piksel Maps][map_lnk] is for viewing products or datasets and interacting with them on a map.

[Data Explorer][exp_lnk] is for browsing products, checking where and when data is available, and inspecting dataset metadata.
