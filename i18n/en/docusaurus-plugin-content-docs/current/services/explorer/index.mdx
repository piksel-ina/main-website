# Piksel Explorer

How can we know exactly **where** and **when** data is available? Before starting any analysis, we can answer this question by inspecting the catalog in the [Data Explorer][exp_lnk].

:::info Start exploring
Open the [Data Explorer][exp_lnk]
:::

## Map or Explorer {#map-or-explorer}

The [Data Explorer][exp_lnk] and [Piksel Maps][map_lnk] look similar, but they are built for different purposes.

Use [Piksel Maps][map_lnk] if:

- You want to visualize a product or dataset and interact with the data in a map viewer

Use the [Data Explorer][exp_lnk] if:

- You want to know exactly where and when a given dataset is available

## Available Products {#produk-tersedia}

The Data Explorer provides **11 satellite data products** covering an archive of optical and radar imagery from several missions.

![Product list in the Piksel Explorer](/img/explorer/explorer-products-list.webp)

### Landsat Family (USGS)

Landsat Collection 2 Level-2 imagery with two variants per satellite: Surface Reflectance (`sr`) for surface reflectance analysis, and Surface Temperature (`st`) for land surface temperature monitoring.

| Product | Description |
| --- | --- |
| `ls5_c2l2_sr` | Landsat 5 — Surface Reflectance |
| `ls5_c2l2_st` | Landsat 5 — Surface Temperature |
| `ls7_c2l2_sr` | Landsat 7 — Surface Reflectance |
| `ls7_c2l2_st` | Landsat 7 — Surface Temperature |
| `ls8_c2l2_sr` | Landsat 8 — Surface Reflectance |
| `ls8_c2l2_st` | Landsat 8 — Surface Temperature |
| `ls9_c2l2_sr` | Landsat 9 — Surface Reflectance |
| `ls9_c2l2_st` | Landsat 9 — Surface Temperature |

### Sentinel Family (ESA)

Optical and radar imagery from the European Space Agency's Sentinel missions, including annual composite products dedicated to the Indonesian region.

| Product | Description |
| --- | --- |
| `s1_rtc` | Sentinel-1 — Radiometrically Terrain Corrected (RTC) SAR, derived from Level-1 GRD |
| `s2_l2a` | Sentinel-2 — Collections 2a, 2b, and 2c |
| `s2_geomad_annual` | Sentinel-2 — Annual Geometric Median and MAD composite (14 bands, Indonesia-specific) |
