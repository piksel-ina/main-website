# Interactive Map

[Piksel Map][map] is a web map viewer for discovering, visualising, comparing, and sharing Piksel geospatial data. No specialised GIS software is required.

:::info Start using the map
Open [Piksel Map][map] to follow this guide.
:::

![Piksel Map welcome message](/img/maps/maps-01-welcome.webp)

## Get to know the interface

After closing the welcome message, you will see the **Workbench** on the left, the map view in the centre, and application controls at the top and right.

![Piksel Map main interface](/img/maps/maps-02-empty-workbench.webp)

1. The **Workbench** lists added layers and their settings.
2. **Explore map data** opens the Piksel data catalogue.
3. **Upload data** adds data from your computer or a URL.
4. The top bar contains map settings, help, language selection, Stories, and Share / Print.

![Piksel Map top-bar controls](/img/maps/maps-03-top-bar.webp)

## Basic navigation

Use the mouse wheel or the **+** and **−** buttons to zoom. Drag the map to move around. The right-side controls also reset zoom, centre on your location, compare layers, and measure lines.

![Map navigation controls](/img/maps/maps-04-map-tools.webp)

## Change the basemap

Open **Map Settings** to select 2D or 3D view and change the basemap. Current choices include CARTO, OpenStreetMap, ESRI World Imagery, and Rupabumi Indonesia (BIG).

![Basemap choices](/img/maps/maps-05-basemap-picker.webp)
