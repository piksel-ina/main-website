# Piksel Sandbox

Piksel Sandbox is a JupyterLab workspace for exploring and analyzing geospatial data. It includes compute resources, a prepared Python environment, and a data catalogue. Users can begin their analysis without setting up each part separately.

Sandbox offers several compute profiles for different kinds of work. Users can request additional resources when the default profile is not enough. The Python environment is built with uv and ready to use.

Open Data Cube provides a catalogue of data ready to load in JupyterLab. The included notebooks and tutorials introduce Earth observation analysis with Python. They also provide a starting point for developing prototypes.

## Accessing Piksel Sandbox

Anyone can apply for access through the [registration form](https://piksel.big.go.id/register). The form asks for the applicant’s organisation or role, intended use of Sandbox, and compute requirements. The Piksel team reviews each request using this information.

Approved applicants receive sign-in details at their registered email address.

## Getting Started with Piksel Sandbox

Once an account is available, users can sign in to Piksel Sandbox and prepare a workspace for analysis.

See [Getting Started with Piksel Sandbox](./sandbox-getting-started) to choose a compute profile and start JupyterLab.
