# Menghitung Luas Area Pertambangan

## Ringkasan

Modul ini bertujuan untuk memberikan contoh penggunaan metode Bare Soil Index (BSI) untuk menghitung luas wilayah pertambangan. BSI adalah indeks spektral yang memanfaatkan perbedaan reflektansi spektral antara tanah terbuka dengan vegetasi dan air untuk mengidentifikasi area tanah yang tidak tertutup vegetasi. Lokasi yang digunakan sebagai contoh adalah area pertambangan nikel di Pulau Gag, Raja Ampat, Provinsi Papua Barat.

## Tahapan

1. Memuat library
2. Menentukan wilayah
3. Memuat indeks data
4. Membuat cloud mask
5. Membuat median
6. Menghitung BSI
7. Menghitung luas wilayah

## Hasil

Luas area pertambangan berhasil dihitung menggunakan data Sentinel-2 dan metode Bare Soil Index (BSI). Penggunaan BSI dapat digunakan juga untuk menghitung luas lahan terbuka lain nya.
