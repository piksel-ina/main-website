# Ketahanan Pangan

Data satelit mendukung pertanian presisi dengan memantau kesehatan tanaman, stres akibat kekeringan atau hama, serta kelembapan tanah untuk mengestimasi produktivitas. Informasi ini membantu merencanakan waktu tanam, penggunaan pupuk dan air, serta memprediksi hasil panen. Pemantauan satelit juga mengidentifikasi potensi gagal panen dan dampak perubahan iklim, sehingga menjadi instrumen penting dalam memastikan ketersediaan pangan nasional.
