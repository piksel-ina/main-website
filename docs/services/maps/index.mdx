# Peta Interaktif

[Piksel Map][map] adalah penampil peta berbasis web untuk menemukan, memvisualisasikan, membandingkan, dan membagikan data geospasial Piksel. Tidak diperlukan perangkat lunak GIS khusus.

:::info Mulai menggunakan peta
Buka [Piksel Map][map] untuk mengikuti panduan ini.
:::

![Pesan selamat datang Piksel Map](/img/maps/maps-01-welcome.webp)

## Mengenal antarmuka

Setelah menutup pesan selamat datang, Anda akan melihat **Workbench** di kiri, tampilan peta di tengah, dan kontrol aplikasi di bagian atas serta kanan.

![Antarmuka utama Piksel Map](/img/maps/maps-02-empty-workbench.webp)

1. **Workbench** menampilkan layer yang sudah ditambahkan beserta pengaturannya.
2. **Jelajahi data** membuka katalog data Piksel.
3. **Unggah data** digunakan untuk menambahkan data dari komputer atau URL.
4. Bilah atas berisi pengaturan peta, bantuan, pilihan bahasa, Cerita, dan Bagikan / Cetak.

![Kontrol bilah atas Piksel Map](/img/maps/maps-03-top-bar.webp)

## Navigasi dasar

Gunakan roda tetikus atau tombol **+** dan **−** untuk memperbesar atau memperkecil peta. Seret peta untuk berpindah lokasi. Tombol di sisi kanan juga menyediakan reset zoom, lokasi saat ini, perbandingan, dan pengukuran garis.

![Kontrol navigasi peta](/img/maps/maps-04-map-tools.webp)

## Mengganti peta dasar

Buka **Pengaturan Peta** untuk memilih tampilan 2D atau 3D dan mengganti peta dasar. Pilihan saat ini meliputi Peta Dasar (CARTO), OpenStreetMap, ESRI World Imagery, dan Rupabumi Indonesia (BIG).

![Pilihan peta dasar](/img/maps/maps-05-basemap-picker.webp)
