# Data Explorer

Data Explorer adalah katalog metadata untuk menelusuri data satelit yang tersedia di Piksel. Katalog ini memperlihatkan produk, cakupan ruang dan waktu, serta metadata pada setiap dataset. Dokumentasi produk tersedia pada bagian [Produk Data](/docs/category/data-products/).

:::info Mulailah menjelajah
Buka [Data Explorer][exp_lnk]
:::

## Map atau Explorer {#map-or-explorer}

[Data Explorer][exp_lnk] dan [Piksel Maps][map_lnk] menggunakan sumber data yang sama, tetapi keduanya digunakan untuk kebutuhan yang berbeda.

[Piksel Maps][map_lnk] digunakan untuk melihat dan berinteraksi dengan produk atau kumpulan data pada peta.

[Data Explorer][exp_lnk] digunakan untuk menelusuri produk, memeriksa ketersediaan data berdasarkan ruang dan waktu, serta melihat metadata dataset.

## Panduan Data Explorer

- [Mencari Data](./searching-for-data.md) menjelaskan cara menelusuri data melalui antarmuka Data Explorer.
- [STAC API](./stac-api.md) menjelaskan cara mencari dan mengambil metadata dari katalog melalui kode.
- [Format Ekspor Data](./data-export-formats.md) merangkum endpoint metadata yang tersedia.
