# Piksel Sandbox

Seperti namanya, Piksel Sandbox adalah ruang untuk mencoba ide dan alur analisis geospasial. Memulai analisis sering kali membutuhkan lebih dari sekadar data dan notebook karena pengguna juga perlu menyiapkan sumber daya komputasi, lingkungan Python, serta cara untuk menemukan dan memuat data. Sandbox menyediakan kebutuhan awal tersebut dalam satu tempat agar pengguna dapat mulai bekerja lebih cepat.

Sandbox menyediakan beberapa profil komputasi, sehingga pengguna dapat memilih sumber daya sesuai kebutuhannya. Jika profil awal belum mencukupi, pengguna dapat mengajukan tambahan sumber daya. Lingkungan Python juga sudah disiapkan menggunakan uv, sehingga pengguna dapat langsung mulai bekerja tanpa mengaturnya dari awal.

Untuk mengakses data, Sandbox menggunakan Open Data Cube yang menyediakan katalog data siap dimuat untuk analisis. Notebook pembelajaran dan tutorial juga tersedia agar pengguna dapat mencoba alur kerja secara langsung. Semua yang sudah disiapkan ini membantu mempercepat pembuatan prototipe dan memudahkan pengguna yang masih belajar analisis data pengamatan Bumi dengan Python.

## Akses Piksel Sandbox

Siapa pun dapat mengajukan permohonan akses ke Piksel Sandbox melalui [formulir pendaftaran](https://piksel.big.go.id/register). Formulir pendaftaran meminta informasi tentang organisasi atau peran pengguna, tujuan penggunaan Sandbox, dan kebutuhan komputasi. Tim Piksel meninjau setiap permohonan berdasarkan informasi tersebut.

Apabila permohonan disetujui, informasi untuk masuk akan dikirimkan ke alamat email yang didaftarkan.

## Memulai dengan Piksel Sandbox

Setelah memiliki akun, pengguna dapat masuk ke Piksel Sandbox dan mulai menyiapkan ruang kerja untuk analisis.

Untuk memilih profil komputasi dan menjalankan JupyterLab, lihat [Memulai Piksel Sandbox](./sandbox-getting-started).
