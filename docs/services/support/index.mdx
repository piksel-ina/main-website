# Dukungan dan Kolaborasi

Piksel menyediakan dukungan komprehensif melalui tiga jalur utama:

1. **[Kolaborasi Strategis](./collaboration)** - Peluang kolaborasi dalam pemanfaatan teknologi geospasial dan penginderaan jauh, seperti pengolahan data, analisis, pengembangan platform, hingga program magang.
2. **[Program Pelatihan](./training)** - Pelatihan praktis untuk menemukan, mengolah, dan menganalisis citra satelit serta data geospasial melalui Open Data Cube, Python, workflow berbasis cloud, dan machine learning.
3. **[Pusat Bantuan](./help-center)** - Kanal komunikasi resmi untuk keperluan seputar platform Piksel, seperti akses akun, laporan bug, hingga usulan pengembangan.
