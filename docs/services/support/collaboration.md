# Kolaborasi Strategis

Piksel membuka peluang kolaborasi untuk menjawab berbagai kebutuhan di Indonesia melalui pemanfaatan teknologi geospasial dan penginderaan jauh. Kolaborasi dapat dilakukan bersama instansi pemerintah, perguruan tinggi, organisasi, dan mitra lainnya.

## Pengolahan atau Analisis Geospasial

Kerja sama dalam pengolahan data penginderaan jauh dan analisis geospasial untuk kebutuhan spesifik mitra, apabila ada wilayah yang perlu dipetakan atau permasalahan yang perlu dianalisis dari data satelit.

Kolaborasi dapat memadukan pengetahuan sektoral dan data pendukung dari mitra dengan koleksi citra satelit, infrastruktur komputasi, serta kemampuan pengolahan dan analisis yang tersedia di Piksel.

Contohnya:

- Menggabungkan citra satelit dengan data lapangan atau data tematik milik mitra untuk menjawab kebutuhan sektoral
- Mengembangkan metode dan indikator geospasial sesuai karakteristik wilayah atau isu yang dikaji
- Mengolah data dalam cakupan wilayah atau rentang waktu yang membutuhkan kapasitas komputasi besar

Alur pengajuan mengikuti [Proses Kerja Sama](#proses-kerja-sama).

## Pengembangan Kompetensi

Kerja sama pengembangan kompetensi ditujukan untuk memperkuat kemampuan sumber daya manusia dalam pemanfaatan data geospasial, citra satelit, dan teknologi analisis. Bentuknya dapat berupa program magang atau pelatihan.

### Program Magang

Program magang memberi kesempatan kepada mahasiswa dan lulusan baru untuk terlibat dalam pengolahan data dan pengembangan teknologi geospasial bersama Tim Piksel. Topik dan kegiatannya disesuaikan dengan bidang studi peserta serta kebutuhan institusi pengirim.

Kegiatan magang dapat berupa:

- Mengolah dan menganalisis citra satelit menggunakan Python atau Open Data Cube
- Mengembangkan aplikasi untuk pengolahan atau penyajian data geospasial
- Meneliti dan mengembangkan metode analisis untuk topik tertentu

Program magang dilaksanakan sesuai mekanisme permagangan di Badan Informasi Geospasial (BIG).

### Program Pelatihan

Program pelatihan dapat disesuaikan dengan kebutuhan, tingkat pemahaman, dan profil peserta. Topik serta mekanisme pengajuan dijelaskan pada halaman [Program Pelatihan](../training).

## Kontribusi Terbuka

Kode sumber Piksel tersedia di [github.com/piksel-ina](https://github.com/piksel-ina). Pengembang dapat berkontribusi pada antarmuka pengguna atau skrip analisis geospasial dengan melaporkan masalah, mengusulkan perbaikan, atau mengirim pull request.

## Proses Kerja Sama

1. Pemohon mengajukan usulan kerja sama melalui email Piksel (piksel@big.go.id).
2. Tim Piksel dan Balai Layanan Jasa dan Produk Geospasial BIG menerima dan meninjau usulan.
3. Tim dapat menghubungi pengusul untuk klarifikasi atau diskusi lebih lanjut.
4. Ruang lingkup, jadwal, dan mekanisme pelaksanaan dibahas bersama sesuai kebutuhan.
5. Kerja sama dilaksanakan sesuai ketentuan yang berlaku.
